# 🛒 Trendyol Shopping Bot with Selenium (Java)

This project is a **Java-based Selenium automation bot** that navigates [Trendyol](https://www.trendyol.com), selects products based on specific logic (e.g., category, popularity, availability), and adds them to the basket—just like a real user would!

## ✨ Features

- ✅ Navigates to Trendyol's homepage
- 🧠 Selects and filters products by category or other criteria
- 🛍️ Adds selected products to the shopping basket
- 👀 Mimics real user interactions with waits and scrolls
- 📦 Ready for testing automation or demonstration purposes

## 🧰 Tech Stack

- **Language**: Java 17
- **Automation Framework**: Selenium WebDriver
- **Build Tool**: Maven / Gradle
- **Browser Support**: Chrome (via WebDriver)

### 🛠 Tools & Purpose

- **JUnit**: Manages test execution and provides detailed result tracking.
- **Cucumber & Gherkin**: Enables writing test scenarios in a readable, business-friendly format.
- **Extent Reports**: Generates visually rich and detailed reports for test results.


## 🏁 Getting Started

### Prerequisites
- Java JDK 17 or higher
- Chrome browser installed
- Maven or Gradle
- ChromeDriver (matching your Chrome version)
